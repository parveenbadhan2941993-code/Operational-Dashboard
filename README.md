# 🏭 Operational Dashboard

## 📌 Project Overview
The Operational Dashboard is an end-to-end Business Intelligence project developed using **SQL, Power BI, and DAX** to analyze manufacturing operations and support data-driven decision-making. The project focuses on monitoring production performance, product quality, operational efficiency, and cost trends across multiple factories through interactive dashboards and KPI reporting.

## 🎯 Project Objectives
- Monitor overall production performance.
- Track quality metrics such as Yield % and Scrap %.
- Analyze factory-wise production output.
- Evaluate operational efficiency and performance trends.
- Monitor production costs and efficiency.
- Provide actionable insights through interactive reporting.

## 🛠️ Tools & Technologies
- SQL – Data Cleaning & Exploratory Data Analysis (EDA)
- Power BI – Dashboard Development & Data Visualization
- DAX – KPI and Measure Creation
- Power Query – Data Transformation
- Data Modeling – Relationship Management

## 📊 Project Workflow
### 1. Data Cleaning
Cleaned and transformed raw manufacturing data using SQL by handling missing values, removing duplicates, and standardizing data formats.

### 2. Exploratory Data Analysis (EDA)
Performed SQL-based analysis to identify production trends, factory performance patterns, operational inefficiencies, and quality metrics.

### 3. Data Modeling & DAX
Built relationships between tables and created business KPIs using DAX to measure production, quality, and operational performance.

### 4. Dashboard Development
Designed interactive Power BI dashboards with KPI cards, trend analysis, slicers, and drill-down capabilities.

## 📈 Dashboard Pages
- **Executive Dashboard** – Tracks Production, Yield %, Scrap %, and Performance Index.
- **Factory Analysis** – Compares production performance across factories.
- **Cost & Efficiency Dashboard** – Evaluates operational costs and efficiency trends.
- **Product Analysis** – Monitors product-level production and quality performance.

## 📌 Key Metrics
- Total Production
- Total Good Production
- Total Scrap
- Yield Percentage
- Scrap Percentage
- Performance Index
- Hourly Average Production
- Hourly Good Production

### Formula Logic
- Yield % = Good Production ÷ Total Production
- Scrap % = Scrap Quantity ÷ Total Production
- Performance Index % = Actual Output ÷ Target Output
- Hourly Average Production = Total Production ÷ Working Hours
- Hourly Good Production = Total Good Production ÷ Working Hours
